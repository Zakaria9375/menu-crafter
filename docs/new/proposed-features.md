## Feature Implementation Checklist

### Phase 1: Core (MVP)

- [ ] **Online Ordering**: Basic order flow (dine-in via QR)
- [ ] **Menu Management**: Categories, items, modifiers, dietary labels
- [ ] **QR Code Menu**: Generate and display QR codes per table
- [ ] **Website Builder**: Basic CMS with templates
- [ ] **Working Hours**: Operating schedule per tenant
- [ ] **Taxes**: Tax configuration
- [ ] **Notifications**: Order status updates
- [ ] **Analytics & Reporting**: Basic dashboard stats
- [ ] **Contact Form**: Public inquiry form
- [ ] **Chat/Help Support**: Knowledge base integration

### Phase 2: Pro Features

- [ ] **Tableside Ordering**: Full cart + checkout from customer device
- [ ] **Table Reservations**: Booking system with time slots
- [ ] **Pre-Order**: Schedule orders for future pickup/delivery
- [ ] **Online Payments**: Stripe/PayPal integration
- [ ] **Delivery Zone Management**: Define delivery areas and fees
- [ ] **Order Taking App**: Staff-facing mobile app for order management
- [ ] **Order Printing**: Receipt templates and printer integration
- [ ] **Custom Working Hours**: Per-category/item availability
- [ ] **Tipping (Gratuity)**: Add tip option at checkout
- [ ] **Inventory**: Track stock levels, auto-mark sold out
- [ ] **Packaging Fee**: Add packaging costs to orders
- [ ] **Premium Templates**: Additional website themes
- [ ] **Custom Domain**: CNAME/DNS setup for custom domains
- [ ] **Multi-Language**: Translation system for menu and website
- [ ] **Custom Checkout Fields**: Add custom questions at checkout
- [ ] **Promotions & Discounts**: Percentage/fixed discounts, time-based
- [ ] **Coupons & Promo Codes**: Generate and validate codes
- [ ] **Restaurant CRM**: Customer database with order history
- [ ] **SEO Tools**: Meta tags, sitemap, structured data
- [ ] **Restaurant Feedback**: Post-order review collection
- [ ] **Multi-Location**: Manage multiple venues under one account
- [ ] **Integrations**: Third-party service connections

### Phase 3: Enterprise Features

- [ ] **Branded Mobile App**: White-label mobile app
- [ ] **Google Ordering**: Google Food Ordering integration
- [ ] **Order Throttling**: Limit orders per time slot to manage kitchen load
- [ ] **Processing Fee**: Pass payment fees to customer
- [ ] **Age Verification**: Age gate for alcohol menus
- [ ] **Remove Branding**: Hide "Powered by MenuCrafter"
- [ ] **Item Recommendations**: AI-powered upselling
- [ ] **Multiple Menus**: Different menus for different times/occasions
- [ ] **Gift Cards**: Digital gift card system
- [ ] **Email Marketing**: Campaign builder with templates
- [ ] **SMS Marketing**: Text message campaigns
- [ ] **Review Management**: Aggregate and respond to reviews
- [ ] **Marketing Automation**: Triggered campaigns (abandoned cart, etc.)
- [ ] **Custom Email Address**: Branded email (e.g., orders@cafe.com)
- [ ] **Audit Logs**: Track all admin actions
- [ ] **API Access**: Public API for developers
- [ ] **10 GB Storage**: Increased media storage

### Add-ons (Paid Separately)

- [ ] **Loyalty Program**: Points-based rewards system
- [ ] **Website Development Service**: Custom design and setup
